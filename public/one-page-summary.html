IDLE TESTING MONITOR - One Page Summary

Presentation snapshot of implemented capabilities, reliability upgrades, and current status.

Project Objective

Build a web-based monitor to run and track idle testing across multiple systems with loop-based data capture, resilient SSH behavior, and clear operational visibility for both users and administrators.

Stack

  • Backend: Node.js + Express + ssh2
  • Realtime: WebSocket updates
  • Frontend: HTML, CSS, JavaScript
  • Runtime: Windows deployment, default on port 80

Key Features Delivered

  • Dynamic Add System form with scalable responsive layout
  • Role-based access (User/Admin) with admin-auth actions
  • Loop-wise summary extraction for C6 and PC6
  • Log popup + per-system page + log download support
  • OS type selector: CentOS, Windows, Custom credentials
  • Conditional credential fields: shown only for Custom
  • Stop flow with reason prompt + confirmation + persisted reason

Reliability Improvements

  • SSH recovery retries up to 1 hour for transient connectivity failures
  • No loop skipping after SSH recovery; failed loop is retried
  • Recovery message shown with reconnect wait time
  • Loop 0 immediate capture plus scheduled timed loops
